# 🍰 Cake on Wheels - Online Cake Ordering Platform MVP

A premium, fully responsive online marketplace platform where anyone can order artisanal cakes with Cash on Delivery (COD). Anyone can register as a seller, list cakes, set discounts, and track order stages, while admins oversee global analytics, modify order pipeline logistics, and manage promotional codes.

This project is built using **React + Vite + Vanilla CSS** and is designed specifically as a high-fidelity portfolio presentation. It supports a **hybrid database model**: runs instantly in-browser using LocalStorage, or connects to a live **Supabase** cloud database when environment variables are supplied.

---

## 🚀 Quick Start (Local Run)

1. **Install Dependencies**:
   ```bash
   npm install
   ```
2. **Launch Development Server**:
   ```bash
   npm run dev
   ```
3. **Open in Browser**: Open `http://localhost:5173` (or the URL shown in your terminal).

## ☁️ Cloud Database Setup (Supabase)

To connect this application to a persistent live cloud database for free:

1. Create a free account at [Supabase](https://supabase.com/).
2. Create a new project.
3. Navigate to the **SQL Editor** in your Supabase dashboard and run the SQL schema queries below to initialize the database tables.
4. Go to **Project Settings -> API** and copy your `Project URL` and `anon public` key.
5. Create a `.env` file in the root of this project and paste your keys:
   ```env
   VITE_SUPABASE_URL=https://your-project-id.supabase.co
   VITE_SUPABASE_ANON_KEY=your-anon-public-key
   ```
6. Restart your dev server. The app will detect the variables and automatically switch from LocalStorage to Cloud mode!

### Supabase Table Schema Queries:

```sql
-- 1. Create Users profile table
CREATE TABLE users (
  id UUID PRIMARY KEY,
  email TEXT NOT NULL UNIQUE,
  role TEXT CHECK (role IN ('buyer', 'seller', 'admin')) NOT NULL,
  name TEXT NOT NULL,
  shop_name TEXT,
  address TEXT,
  phone TEXT,
  created_at TIMESTAMP WITH TIME ZONE DEFAULT timezone('utc'::text, now()) NOT NULL
);

-- 2. Create Cakes listing table
CREATE TABLE cakes (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  name TEXT NOT NULL,
  description TEXT NOT NULL,
  price NUMERIC(10, 2) NOT NULL,
  image_url TEXT,
  category TEXT NOT NULL,
  rating NUMERIC(3, 2) DEFAULT 5.0,
  discount NUMERIC(3, 0) DEFAULT 0,
  special_sale BOOLEAN DEFAULT false,
  stock NUMERIC(5, 0) DEFAULT 10,
  seller_id UUID REFERENCES users(id) ON DELETE CASCADE NOT NULL,
  seller_name TEXT NOT NULL,
  reviews JSONB DEFAULT '[]'::jsonb,
  created_at TIMESTAMP WITH TIME ZONE DEFAULT timezone('utc'::text, now()) NOT NULL
);

-- 3. Create Orders table
CREATE TABLE orders (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  customer_id UUID REFERENCES users(id) ON DELETE CASCADE,
  customer_name TEXT NOT NULL,
  customer_phone TEXT NOT NULL,
  shipping_address TEXT NOT NULL,
  items JSONB NOT NULL, -- Holds array of items with cake_id, name, price, qty, etc.
  total NUMERIC(10, 2) NOT NULL,
  discount_amount NUMERIC(10, 2) DEFAULT 0.00,
  final_total NUMERIC(10, 2) NOT NULL,
  status TEXT DEFAULT 'Placed' CHECK (status IN ('Placed', 'Accepted', 'Preparing', 'Out for Delivery', 'Delivered', 'Cancelled')),
  delivery_date TEXT NOT NULL,
  delivery_time TEXT NOT NULL,
  created_at TIMESTAMP WITH TIME ZONE DEFAULT timezone('utc'::text, now()) NOT NULL
);

-- 4. Create Coupons table
CREATE TABLE coupons (
  code TEXT PRIMARY KEY,
  discount_type TEXT CHECK (discount_type IN ('percent', 'fixed')) NOT NULL,
  discount_value NUMERIC(10, 2) NOT NULL,
  active BOOLEAN DEFAULT true,
  created_at TIMESTAMP WITH TIME ZONE DEFAULT timezone('utc'::text, now()) NOT NULL
);

-- Seed pre-created coupons
INSERT INTO coupons (code, discount_type, discount_value)
VALUES 
  ('CAKEWOW', 'percent', 20.00),
  ('SWEET10', 'percent', 10.00)
ON CONFLICT (code) DO NOTHING;
```

## 🚀 Free Deployment Guide (Vercel & Netlify)

### Option A: Vercel (Recommended)
1. Push your code to a GitHub repository.
2. Sign up on [Vercel](https://vercel.com/) and click **Add New Project**.
3. Import your GitHub repository.
4. Expand **Environment Variables** and add:
   - Name: `VITE_SUPABASE_URL` | Value: *[Your Supabase URL]*
   - Name: `VITE_SUPABASE_ANON_KEY` | Value: *[Your Supabase Anon Key]*
5. Click **Deploy**. Vercel will build and host your app on a free `https://project-name.vercel.app` URL.

### Option B: Netlify
1. Log in to [Netlify](https://www.netlify.com/) and select **Import from GitHub**.
2. Authorize Netlify and import your repository.
3. In the Build settings, add environment variables inside **Environment variables** settings under Site details.
4. Click **Deploy Site**. Netlify will host it on a free `https://project-name.netlify.app` URL.
